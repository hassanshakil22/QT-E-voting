# QT E-Voting  

A C++ voting application built with **Qt** and **SQLite**, developed by a team of three.  

### Features  
- Secure voter authentication  
- Real-time vote counting  
- Visual graphs for results *(no export functionality)*  
- SQLite database for storage

### Requirements  
- Qt 5+  
- SQLite3  

### Usage  
1. Clone the repo.  
2. Open in Qt Creator and build.  
3. The app auto-creates `voting.db` on first run.
4. do change the path of db in main.cpp 


*Note: Graphs display results but cannot be exported.*
